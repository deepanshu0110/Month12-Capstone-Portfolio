## What this covers

The Days 192–196 capstone builds a full pipeline end to end — data ingestion and cleaning, a model + retrieval-augmented generation layer, deployment packaging, and a written final report aimed at a business audience rather than a technical one.

Days 197–199 shift into **ResumeGapAI**, the program's first standalone product: scoping it from scratch, building the core matching logic, then polishing and deploying it publicly.

## Where ResumeGapAI lives now

The notebook work here was the build phase. The finished, deployed product has its own repository:
**[ResumeGapAI](https://github.com/deepanshu0110/ResumeGapAI)** — live at [resumegapai.streamlit.app](https://resumegapai.streamlit.app)
